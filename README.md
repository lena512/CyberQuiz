# CyberQuiz

**CyberQuiz** — корпоративная обучающая платформа, предназначенная для развития навыков информационной безопасности сотрудников. Система позволяет изучать учебные материалы, проходить тестирование и выполнять практические задания, направленные на подготовку к противодействию киберугрозам.

## Текущая версия

**Версия:** 0.0.3

Данные тестирования сохраняются в PostgreSQL. Разработка продолжается.

## Технологии

- **Python 3.13** — язык программирования.
- **Django 6.1.3** — веб-фреймворк.
- **PostgreSQL 16** — база данных.
- **Docker** — средство контейнеризации приложения.

## Запуск

Репозиторий: https://github.com/lena512/CyberQuiz
Ветка: lab3
Pull Request: https://github.com/lena512/CyberQuiz/pull/3
Образ: lena512/mispisit-lab1:0.0.3
Страница образа: https://hub.docker.com/r/lena512/mispisit-lab1

```bash
git clone -b lab3 https://github.com/lena512/CyberQuiz
cd CyberQuiz
docker compose up -d
```

Приложение и база данных поднимаются вместе. После запуска приложение доступно в браузере по адресу:

```text
http://localhost:8080
```

Список результатов сначала пустой. Новая попытка, созданная на странице тестирования, сохраняется в базе и остаётся после перезапуска:

```bash
docker compose down
docker compose up -d
```

## Локальная сборка Docker-образа

Для самостоятельной сборки образа из исходного кода выполните команды в корневой папке проекта:

```bash
docker build -t lena512/mispisit-lab1:0.0.3 .
docker run --rm -p 8080:8080 lena512/mispisit-lab1:0.0.3
```
