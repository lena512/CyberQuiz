# CyberQuiz

**CyberQuiz** — корпоративная обучающая платформа, предназначенная для развития навыков информационной безопасности сотрудников. Система позволит изучать учебные материалы, проходить тестирование и выполнять практические задания, направленные на подготовку к противодействию киберугрозам.

## Текущая версия

**Версия:** 0.0.1

На данном этапе реализована стартовая страница проекта. Разработка продолжается.

## Технологии

- **Python 3.13** — язык программирования.
- **Django 6.1.3** — веб-фреймворк.
- **Docker** — средство контейнеризации приложения.

## Запуск проекта с помощью Docker

Для запуска опубликованного образа необходимо выполнить следующие команды:

```bash
docker pull lena512/mispisit-lab1:0.0.1
docker run --rm -p 8080:8080 lena512/mispisit-lab1:0.0.1
```

После запуска приложение будет доступно в браузере по адресу:

```text
http://localhost:8080
```

## Локальная сборка Docker-образа

Для самостоятельной сборки образа из исходного кода выполните команды в корневой папке проекта:

```bash
docker build -t cyberquiz:0.0.1 .
docker run --rm -p 8080:8080 cyberquiz:0.0.1
```

## Структура проекта

- `config/` — настройки и маршрутизация Django-проекта.
- `core/` — основное приложение.
- `templates/` — HTML-шаблоны страниц.
- `static/` — статические файлы, включая CSS.
- `manage.py` — инструмент управления Django-проектом.
- `requirements.txt` — список зависимостей проекта.
- `Dockerfile` — инструкции для сборки Docker-образа.
- `.dockerignore` — список файлов, исключаемых из Docker-сборки.
